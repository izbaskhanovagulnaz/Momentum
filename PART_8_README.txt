PART 8 — AUTOMATIC PWA UPDATES

What changed:
- Momentum checks for updates when opened.
- It checks again when returning from the background.
- It checks every 60 seconds while open.
- A banner says "Доступна новая версия".
- Tap "Обновить" to activate and reload the new version.
- No need to remove or re-add the Home Screen icon.

IMPORTANT FOR THE FIRST INSTALL OF THIS UPDATE:
1. Run deploy.bat.
2. Open Momentum from the Home Screen.
3. Fully close it once and open again.
After this one transition, all future releases use the in-app update button.
