PART 13 — GOALS WITH MOTIVATION PHOTOS

Added:
- create goals;
- edit goals;
- delete goals;
- upload or replace a motivation photo;
- remove a goal photo;
- period, deadline, current value, target value and unit;
- automatic progress calculation;
- completed-goal status;
- Firestore synchronization between devices;
- mobile bottom-sheet editor and responsive desktop cards.

Photos are resized and compressed before saving to keep synchronization fast.

Run deploy.bat and update the installed PWA when prompted.
